# О фактическом выводе

В этой поставке не приведены вымышленные образцы Windows-серийников и температур.
Ни один Windows-провайдер в среде подготовки не запускался. Готовые запросы для
пользовательского запуска лежат в queries/windows. Здесь сохранён только фактический
отчёт проверки Windows-реестра на Linux; он проверяет метаданные/запросы без чтения WinAPI.
