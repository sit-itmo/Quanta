# `hal.capabilities`

Implemented HAL operations bitmask. Общая метрика, доступная в каталоге всех платформ.

Тип: `QUANTA_U64`. Единица: `безразмерная`. Свойство, читается один раз за сессию.

Источник: quanta_hal_get_info выбранного HAL; собственных системных вызовов нет.

Значение НЕ является измерением доступности операций: права и устройства проверяются во время обращения к HAL.
