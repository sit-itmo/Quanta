# `quanta.version`

Quanta version. Общая метрика, доступная в каталоге всех платформ.

Тип: `QUANTA_STRING`. Единица: `безразмерная`. Свойство, читается один раз за сессию.

Источник: константа версии сборки; операционная система и HAL не требуются.

Значение принадлежит текущей сессии и не описывает другую машину.
