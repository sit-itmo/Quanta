# `hal.name`

Selected hardware backend. Общая метрика, доступная в каталоге всех платформ.

Тип: `QUANTA_STRING`. Единица: `безразмерная`. Свойство, читается один раз за сессию.

Источник: quanta_hal_get_info выбранного HAL; собственных системных вызовов нет.

Значение принадлежит текущей сессии и не описывает другую машину.
