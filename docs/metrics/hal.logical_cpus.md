# `hal.logical_cpus`

HAL logical CPU count. Общая метрика, доступная в каталоге всех платформ.

Тип: `QUANTA_U64`. Единица: `count`. Свойство, читается один раз за сессию.

Источник: quanta_hal_get_info выбранного HAL; собственных системных вызовов нет.

Неизвестное количество CPU возвращается как UNSUPPORTED, а не как нулевое измерение.
