# INVQ 1: спецификация реализованного подмножества

Запрос компилируется в план один раз до сбора. Это декларативный язык, не shell,
SQL или язык общего назначения. Произвольный код и произвольные пути к источникам
в запросах не выполняются. Публичный C API `inv_paths` существует для портов и
тестовых fixtures; через CLI корни `/proc`, `/sys`, `/etc` не переопределяются.

## Директивы

```text
version 1;
mode file | tui | gui;
format human | table | csv | md;
once;
every 1s;
redraw 200ms;
history 5m;
for 30s;
count 100;
output "new-file.csv";
layout grid(columns=3);
strict;
```

Директивы завершаются `;`. Глобальная директива не может повторяться. `once`
несовместим с `for` / `count`. Без периодических директив FILE по умолчанию
одноразовый. TUI/GUI работают постоянно, если не ограничены временем/кадрами.

Единицы длительности: `ns`, `us`, `ms`, `s`, `m`, `h`; допустима дробная часть,
например `0.5s`. Длительность положительная, не NaN/Infinity, максимум 7 суток.
Период сбора не меньше 10 ms, история не больше 24 часов. Реальные минимальные
интервалы большинства метрик выше. `strict` запрещает ограничение частоты;
без него период увеличивается до безопасного и печатается диагностика.
`redraw` управляет TUI; GUI в v0.1 имеет собственный предел около 30 FPS.

Один запуск — один mode. Вывод FILE означает stdout либо файл, не второй sink.
`format` в live-режимах не выбирает дополнительный экспорт. `output` разрешён
только в FILE. CLI `--mode` / `--format` явно переопределяют выбранный режим.
Явный `once` из файла нужно удалить при переводе одноразового отчёта в GUI/TUI.

## Выбор

```text
select [optional] selector [as widget(options)] [every duration];
selector = metric_name_or_glob [ { label="glob", ... } ];
expression = selector | rate(selector) | delta(selector);
```

Вместо `selector` после `select` допускается `expression`.
Метрики используют латинские dotted keys. В glob специальны только `*` и `?`:
звёздочка может пересекать точки. Квадратные группы regex/glob не поддерживаются.
Фильтры меток — логическое AND. Неизвестное имя метки проверяется до сбора.
Нет неявного объединения сетевых карт или датчиков в одну сумму/среднее.

```text
select os.memory.*;
select sensor.temperature{chip="coretemp",channel="temp?"};
select optional device.net.mac{ifname="w*"};
select rate(device.net.rx_bytes_total{ifname="enp3s0"});
```

`optional` допускает отсутствие семейства в этой сборке или отсутствие
экземпляров. Он не маскирует PERMISSION_DENIED / IO_ERROR как успешное значение.
Необязательный селектор без экземпляров порождает диагностику, а не фиктивную
нулевую серию. Обычный селектор без экземпляров — ошибка запуска.

`rate`/`delta` допускаются только для `u64` COUNTER. Rate возвращает f64/секунду,
delta — u64 за фактический интервал. Вложенные функции, арифметика, агрегаты,
суммы и произвольный DAG выражений в этой версии **не реализованы**.
Источник включается автоматически; дублирующиеся виды не читают его повторно.

## Виджеты

`value`, `text`, `bar`, `gauge`, `plot`, `table`.

Опции: `title="..."`, `unit="..."`, `min=0`, `max=1`, `precision=2`.
`plot`, `bar`, `gauge` требуют числовой совместимости. `min/max` задаются в
**канонических единицах**, а не в единицах подписи: доля загрузки — `0..1`.
Для bar/gauge следует явно задавать пределы, иначе используется `0..1`.
`table` переключает GUI в табличный вид; таблица общая, а не вложенная в карточку.
Геометрия виджетов не применяется к CSV/Markdown/human.

Преобразования единиц: B → KiB/MiB/GiB/TiB, B/s → соответствующие IEC/s,
`1` → `%`, s → ms; идентичная единица допустима. Это форматирование,
не изменение семантики/единиц машинного CSV. Цельсий → Fahrenheit, Hz → MHz
и произвольные формулы преобразования не реализованы.

Строки заключаются в двойные кавычки. Экранирование: `\"`, `\\`, `\n`, `\r`, `\t`.
Комментарии `# ...` и `// ...` до конца строки. Запрос — максимум 65536 байт,
встроенные NUL запрещены, максимум 128 select. Лексические и семантические
ошибки содержат сообщение; лексические также строку и столбец.

## CLI и коды завершения

`get` удобен для точных ключей и glob; для подписей, rate и фильтров используйте
`run -q` / `run --query-file`. Для запроса со stdin: `--query-file -`.

`--warmup D` — только одноразовый отчёт. Если D меньше периода нужного счётчика,
итог всё ещё может быть WARMUP. Проверяйте фактический status.
`--fail-on-error` возвращает 3, если были ошибки измерений; WARMUP не считается
ошибкой. `--redact` маскирует помеченные sensitive значения в представлении.
`--csv-unsafe-strings` отключает защиту ячеек CSV от формул.

Коды: 0 — обычное завершение / q; 1 — ошибка выполнения/вывода;
2 — запрос/параметры; 3 — нет обязательных экземпляров или fail-on-error;
128+номер сигнала — SIGINT/SIGTERM/SIGHUP. Просмотр каталога не требует root.
